# Robotweax SRT 0.3.4 pin — 20 November 2026

The Robotweax provider now builds from release 0.3.4, revision
`87742777290e6a77e38672ca35701f7184b75526`, verified by archive checksum like the
previous pin. Haivision 1.5.7 and its two compatibility patches are unchanged.
Modules, tests, the benchmark runner and the relay application expect release
`0.3.4`; a 0.3.3 module is rejected by the identity check.

## Poller wake

0.3.4 adds `robotweax_srt_epoll_wake`. The adapter calls it instead of closing a
registered SRT socket, so a Robotweax poller needs no wake socket at all.
`build_features` records `native-wake=epoll-wake`. The socket-close path remains
in the source for a vendor header without the call and is no longer built by
default.

Wake latency through the C++ facade, 200 wakes of a blocked waiter, macOS ARM64
Release, single local runs:

| Robotweax build | p50 | p90 |
| --- | ---: | ---: |
| 0.3.3, OS socket pair (original) | 4,424 µs | 10,934 µs |
| 0.3.3, socket close | 56 µs | 93 µs |
| 0.3.4, vendor wake call | 31 µs | 45 µs |

## Native surface inventory

The audited inventory was brought to the 0.3.4 source and verified against both
pinned trees with `tools/check_native_audit.py`:

- one new exported name, `robotweax_srt_epoll_wake` (86 Robotweax names);
- seven new socket options, `SRTO_ROBOTWEAX_NPD_POLICY`, `SRTO_ROBOTWEAX_NPD_STATS`
  and five `SRTO_ROBOTWEAX_PEERAUTH_*` (94 Robotweax options), all unexposed by
  the wrapper;
- new checksums for the five recorded Robotweax source files and for ten changed
  source-tree C++ headers. Their recorded declaration summaries were checked to
  still exist in the headers; they were not regenerated.

The statistics structure is unchanged, so the 82-metric telemetry catalogue
still covers it. Null packet deletion and peer authentication are not offered
through the provider interface.

## Checks

macOS ARM64 Release: all 22 tests pass, the unmodified Haivision 1.5.7
application exchanges 24 of 24 messages with both providers in both directions,
and the installed bundle resolves both modules.

Throughput qualification was not rerun. Earlier records describe Robotweax 0.3.3
builds and are not re-labelled.
